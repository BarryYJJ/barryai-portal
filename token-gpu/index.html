方法论与口径 READ FIRST

连续指数 vs 时点报价
Token 与 GPU 指数是逐日累积的连续基准序列；RunPod / Azure 是公开目录在采集时刻的一次性快照，两者永不合并展示或合并计算。
单位不可直接换算
USD/百万 Token 与 USD/GPU-hour 是两种独立计量口径。把 GPU-hour 折成 Token 单价，还需要吞吐量、利用率、模型强度与服务效率四个变量，本页不做该换算。
免费口径的覆盖边界
Silicon Data H100/A100 历史始于 2024-09-01，B200 始于 2025-07-31，Token 综合始于 2025-12-01；其他序列保留实际起点。当前直接采集值优先，历史仅补缺；不插值、不前向填充。Ornn 使用官方日度结算历史，日期按源时间戳的日期部分记录；H100 SXM 始于 2024-10-01，其他四条始于 2026-04-05。
新鲜度与失败语义
每个数据集独立展示最近成功采集时间与滞后天数；采集失败或数据陈旧会在状态区明确标出，绝不会用旧数据冒充最新读数。
目录价的定义
RunPod 为 Secure Cloud 专用 Pod 的按需目录价；Azure 为 NCadsH100v5 系列整机零售价按已验证 GPU 数量归一化，两者均不代表实际成交价、折扣或可用容量。
未接入的来源
Google Cloud 与 AWS 未提供满足本项目区域/型号/合约要求且无需认证的稳定轻量端点，本页未接入，不使用猜测数据填补。
