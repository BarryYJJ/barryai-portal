英伟达 / NVIDIA

公司半导体AI算力

一句话

AI 算力卖铲人,大摩半导体 Top Pick(OW,TP 288):FY28 近端增长上限更多由供给决定，长期估值上限仍由 ASIC 替代和终端算力需求决定；公司正从"卖芯片"扩张到 CPU/网络、上游锁产能、下游融资与 LPS 信用支持的全栈基础设施组织者。

投资逻辑(大摩口径为主)

  • 收入与估值:2026 收入看 4100 亿(+90%)、2027 看 6550 亿(+55%),对应 2027 年仅 ~14x PE;管理层称季度收入逼近 1000 亿美元时增速仍在加快(NDR 260710, A)
  • 循环融资风险已量化:生态投资全部清零仅冲击盈利 ~15%;即便盈利 -25% 股价也只回归行业平均估值(大摩闭门 260708)
  • PORTS-Pike 把信用支持落到官方项目：NVIDIA 与 SB Energy 锁定首期 4.25GW 的土地、电力和厂房，由 OpenAI 承租；NVIDIA 对约 4GW 提供 20 年支持，但范围仅为部分租金、电费及约定残值，2028-2030 年分阶段生效。公司称每代系统约对应 150 万颗 GPU、1500亿-2000 亿美元收入，场址可跨多代升级；这些是机会口径而非已确认收入，核心风险转向 OpenAI 信用、担保敞口、交付与再出租效率（来源：NVIDIA锁定PORTS-Pike约4GW基础设施并支持OpenAI长期算力部署_NVIDIA_260817）→ AI资本开支与算力缺口、云厂商。
  • 财报的核心门槛已从 beat 转为预期二阶导：公司 FY2027 Q2 指引约 910 亿美元，而李奇汇总的买方门槛已到 940亿-950 亿美元、下季指引 1070亿-1100 亿美元；因此短期结果即使超预期，也需 Rubin 收入斜率、FY28 可见度、提价传导和中期 Non-GAAP 毛利率共同抬升，才足以制造新的上行预期差。买方数字是预期而非公司结果（来源：beat已成基准，Rubin提价与融资风险决定NVIDIA业绩预期上限_天风海外科技_260826）→ 李奇观点。
  • 需求约束正在从“是否真实”转为“由谁融资”：NVIDIA 已宣布与 Apollo、BlackRock、Blackstone、Brookfield、Goldman Sachs、KKR 建立独立融资平台，目标长期动员超过 5000 亿美元第三方资本；李奇据此把新增 AI Lab、Neocloud、主权 AI 与企业需求的观察点转向信用质量。约25%残值支持仍只是第三方报道口径，适用项目、上限、期限和会计处理待合同/申报文件确认（来源同上）→ AI资本开支与算力缺口、云厂商。
  • 2Q27 后，FY28 的核心从需求存在性转向供给兑现与利润传导：天风海外科技团队估计 FY27/FY28 收入约 4100亿/7000 亿美元，FY28 同比约增 70%，无供给限制时需求或支持接近 8200 亿美元；该组数字是卖方情景而非公司指引。材料同时把 Q3 官方毛利率指引 74%±0.5% 与其 Q4 71%-72%、FY28 72%-73% 预测分开，判断内存涨价约滞后一个季度、系统提价只能覆盖部分成本（来源：供给约束支撑FY28增长，NVIDIA转向AI基础设施生态组织者_天风海外科技_260827）→ DRAM与HBM供需。
  • 2030FY 给出的价值在估值敏感性，而不是另一份“公司指引”：文章把电话会约 70% 的 FY28 增长目标继续上推为 80%-85% 情景，对应收入 7560亿-7770 亿美元；按 68% EBIT margin 计算，EBIT 约 5141亿-5284 亿美元，作者再假设净利润超过 4000 亿美元并得出约 12x 远期 PE。相对其引用的 BBG 5730 亿美元预期，收入情景高约 32%-36%；但增速、利润率、净利润及 PE 均是作者外推，需分别校验 FY27 基数、SBC/股本、税率和正式一致预期，不可当作 NVIDIA 正式 FY28 指引（来源：FY28高增长目标与2790亿美元锁单强化收入可见度_2030FY_260827）。
  • 资产负债表开始直接参与销售闭环：天风称制造、供应和产能承诺由 1190 亿美元升至 2790 亿美元，应收周转升至 60 天，部分客户付款期延长至 90 天至一年；180K 配图进一步列示截至 2026-07-26 的未来承诺合计 3660 亿美元，其中供应与产能 2790 亿、云服务协议 290 亿、尚未开始的数据中心租赁 250 亿、股权投资 250 亿、资本开支 80 亿。另一配图称 NVIDIA 对部分 Neocloud 产能提供 take-or-pay、并分享高于保底线的租金收入，使硬件销售、供应商信用和项目融资进入同一闭环；合同范围、担保底线和会计敞口仍待申报文件核对（来源：供给约束支撑FY28增长，NVIDIA转向AI基础设施生态组织者_天风海外科技_260827；FY28供给约束与Neocloud融资结构强化NVIDIA中期预期_180K_260827）→ AI资本开支与算力缺口、云厂商。
  • 真正的长期隐患:云厂商 capex 可持续性——一旦有头部玩家率先缩减采购,全行业门槛同步下行 → AI资本开支与算力缺口
  • 需求结构:AI labs 约占总需求 20%;某原 ASIC 路线的头部前沿模型厂,英伟达参与度升至近 50%(NDR 260710)
  • 投资者结构:路演重点之一是主动吸引价值型资金;材料称公司超 50% 现金流用于分红回购,试图用"高成长+价值属性"缓解成长基金持仓上限后的估值压力（来源：英伟达路演总结：价值资金、Rubin出货与内存紧缺_来源未知_260715，2026-07-10）
  • 回调中的负面叙事需要拆分:2023-2024 年反复出现的"NVDA 要崩"预言并未构成事实性反转;当前 CSP 融资风险、内存利润过高、韩国分润/关税等问题更像长期已知变量,市场下跌后才被集中后验解释。核心跟踪仍是需求、供给约束与 capex 持续性,而不是盘面先跌后的叙事漂移（来源：其实什么都没变，继续保持耐心_利文斯顿_260719，2026-07-19）。
  • 份额变化要盯:云厂商计算支出中 GPU 份额已从 90% 降至 60-65%;开源蒸馏小模型冲击有限(总需求不萎缩、结构分化)

产品路线

  • Groq 收购:Vera Rubin 管 prefill、Groq(SRAM)管解码,建议高价值 token 场景 25% Groq + 75% Rubin;Groq LP30 三星代工 Q3 出货(GTC 260316)
  • Rubin Ultra:管理层否认推迟至 2028,"明年"出货;但承认硬件形态会调整,现有 Kyber 机柜将被新一代方案替换,800V 供电与光互联扩容仍按计划推进（来源：英伟达路演总结：价值资金、Rubin出货与内存紧缺_来源未知_260715，2026-07-10）
  • Bloomberg 报道称基于 Vera Rubin 的计算系统已交付主要 AI 公司并即将投入使用,OpenAI 计划在 2026 年三季度"大规模"采用,CoreWeave、谷歌云、Azure、Meta、戴尔等也在使用 Rubin 系统。这是此前"Rubin 是否延期/形态调整"争议后的正向交付验证,但仍需跟踪量产爬坡、良率和整机柜部署节奏（来源：英伟达称新一代 Vera Rubin 设计即将交付客户（260721）_Bloomberg_260721，2026-07-21）。
  • 260826 前瞻把 Rubin 的验证点进一步拆成“量产”与“收入确认”：官方资料支持 Vera Rubin NVL72 正在量产爬坡，Kyber 也是 Oberon 后继机架；但 Rubin Ultra 于 2026Q4 流片、2027H2 落地、双 die/四 die 版本、Kyber 商业化延后及多 Oberon 过渡方案均属李奇渠道判断，需等待公司与供应链披露（来源：beat已成基准，Rubin提价与融资风险决定NVIDIA业绩预期上限_天风海外科技_260826）→ 李奇观点。
  • Rubin CPX 据郭明錤称已重启并整体重构：其产业调查称新版 CPX 将于 1Q27 开始生产，改用 168GB HBM4 和独立 MGX ETL 机柜，与 Vera Rubin NVL72 按 1:1 GPU 数量配比完成 prefill/decode 分离；互联域则收缩为托盘内 8 卡 NVLink，跨托盘/模块改走 Spectrum-6 Ethernet 铜连接与 OSFP 光连接。若属实，CPX 已从旧版 128GB GDDR7 专用卡变为同时抬升 HBM4、网络、供电和液冷价值量的系统产品；全部规格、时点和配比仍是单一供应链来源，待 NVIDIA 正式路线图确认（来源：Rubin CPX重启并转向HBM4独立机柜，prefill推理抬升内存网络与液冷需求_郭明錤 Ming-Chi Kuo_260831，质量 B）→ DRAM与HBM供需、光模块与网络、AI资本开支与算力缺口。
  • NVL72 整机柜 token 处理量据称达到上一代 10 倍,数据由 CoreWeave 实测;英伟达还罕见直接对标称 Vera 微处理器运行 Python 代码速度比 AMD Turin 快 18 倍。若后续云厂商实测复现,性能叙事会从单芯片指标转向整机柜吞吐、自动化组装和液冷系统工程能力（来源：英伟达称新一代 Vera Rubin 设计即将交付客户（260721）_Bloomberg_260721，2026-07-21）→ 云厂商。
  • CPU 目标今年 200 亿美元,近半来自 head node 之外;NemoClaw 企业 Agent 平台(Nemotron 联盟:Cursor/Mistral/Perplexity)
  • 供给约束:因存储供应不足被迫将某产品内存规格减半;内存短缺可能持续数年。管理层口径是"算力、网络、内存"可互相调剂,但这更像短缺下的硬件架构折中,不是需求走弱 → DRAM与HBM供需（来源：英伟达路演总结：价值资金、Rubin出货与内存紧缺_来源未知_260715，2026-07-10）
  • 下一代系统提价的经济实质是存储稀缺租向下游穿透：The Information 援引两名知情人士称，2027 年交付的 Grace Blackwell 300 与 Vera Rubin 200 系统拟涨价约 17%，内存及其他组件成本是部分驱动。Barry 判断这不是 GPU 裸芯片突然变贵，而是 HBM/DRAM 的定价权强到 NVIDIA 选择转嫁；若存储通过扩产健康缓解，NVIDIA 更可能先获得系统毛利与出货双重选择权，而非立即同比例降价，产业链再由“价格牛”切换到“数量牛”。公司尚未置评，且客户通知不等于所有合同均已不可撤销锁价（来源：英伟达AI芯片系统拟涨价17%，下一代机柜成本上移_The Information_260822，质量 B；存储瓶颈推动NVIDIA系统涨价，缓解后价值由价格转向出货_桨桨观点_260823）→ 桨桨观点、DRAM与HBM供需、云厂商。
  • 2607 观点纪要把英伟达后续代际升级的核心变量拆成"每瓦/每美元 token 产出":GB 系列生命周期约一年半,Rubin/Rubin Ultra 等小迭代可能压缩至半年,Feynman 等大升级约一年。只要老设备残值不崩、下游 token ROI 仍高,更快的产品迭代会抬高 capex 强度而不是伤害需求（来源：模型能力跃迁推动推理ROI、Agent负载和算力资源争夺，进而重估DRAM、先进制程、CoWoS、光通信、PCB与电力供给曲线。_来源未知_260722，2026-07）。
  • 每 GW 收入机会随系统代际抬升：管理层口径经天风整理为 Hopper/Blackwell/Vera Rubin 每 GW 年收入机会约 180亿/250亿/400 亿美元，Feynman 预计超过 600 亿美元；Rubin 的提升来自 GPU 之外的 Vera CPU、网络与系统内容量。电力成为最稀缺资源后，竞争指标应从单芯片性能转向每瓦 token 与客户收入，但 Feynman 数字仍属前瞻情景（来源：供给约束支撑FY28增长，NVIDIA转向AI基础设施生态组织者_天风海外科技_260827）→ AI资本开支与算力缺口、Token经济性。
  • AWS 订单把需求验证延伸到 Rubin Ultra：180K 称 AWS 计划在 2027-2028 年额外部署超过 200 万颗 Blackwell Ultra、Rubin 与 Rubin Ultra GPU，叠加此前 GTC 宣布的 2026 年超 100 万颗 GPU。文章未展示 AWS 合同、不可撤销订单或交付表，先作为二手需求线索；验证点是 AWS 正式 CapEx、实例上线、Rubin 系统验收及 NVIDIA 收入确认（来源：FY28供给约束与Neocloud融资结构强化NVIDIA中期预期_180K_260827）→ 云厂商。
  • 全代际租金曲线支持存量资产重估，但证据仍偏弱：8 月二手 Neocloud 中位图称 B200/H200/H100/A100 租金均较此前上行，终点约 6.5/4.2/3.5/2.0 美元/GPU/小时。若可由可追溯报价持续验证，意味着 NVIDIA 的需求不只集中在最新卡，而会在新卡供不应求时向 Hopper/Ampere 下沉，延长旧 GPU 经济寿命；现阶段因样本、地区、合约期限、网络存储与 SLA 均未披露，不把精确价格纳入基准假设（来源：全代际NVIDIA GPU租金上涨，存量算力资产重估_少数派观点局_260823，质量 C）→ 云厂商、AI资本开支与算力缺口。
  • B300 单机与集群收入容量：单一产业专家称 GLM-5.2 在未优化 B300 裸机、真实 Agentic 场景下总吞吐 31.2 万 tok/s、缓存命中 95%；按其 1400 万元现货价和 45% 利用率假设，单机约 16.2 个月回本，128 台以上集群叠加 PD 分离、大 EP 与跨机 KV 调度后约 5.4-7.8 个月。该组数字只证明高负载下的潜在收入容量，尚缺计费结构、SLA、持续吞吐和付费流量验证（来源：GLM-5.2在B300上的推理收入容量与集群回本测算_产业专家交流_260726，质量 B）→ Token经济性。

用户判断

  • 2026-08-27｜Barry 判断：Rubin 上量后 Blackwell 的名义租金下降可能只是代际折价，不能单独解释为 NVIDIA 需求转弱；应改看单位有效 Token 成本，并要求同代际租金、利用率、长约、订单/预付款及融资条件共同恶化后再升级风险判断（来源：GPU租金需按单位Token与代际迁移解读，9月反弹宜逢高提款_蔡神与Barry_260827）→ 桨桨观点、Token经济性、云厂商。
  • 2026-08-25｜Barry 判断：若 CSP 从绑定单一模型转为分发多种闭源与开放模型，短期为每个模型定制 ASIC 的经济性和 time-to-market 都会下降，GPGPU 的通用性因而获得叙事重估；英伟达可作为底仓，而非仅依赖最新一代芯片稀缺性的交易。
  • 验证边界：这是 Barry 的产业判断，不是已确认份额变化。需跟踪 CSP 的 GPU/ASIC CapEx Mix、模型迁移工程量、正式云实例供给及 NVIDIA 推理份额；路演所称“需要约 200 名工程师调试两周”等数字不写入基准假设。
