一句话

单位 Token 价、单位任务成本、模型 Mix 与留存必须联合观察；Barry 8 月 25 日路演判断（待核验）是，模型路由与成熟能力价格战可能使 Token 增长快于模型收入，而 Agent 导流又可能把后续渗透前置到 3Q26。

拐点判断

  • 硬件降本远超摩尔定律:英伟达/博通每年压低 token 单位成本 60-70%(摩尔定律年化 12%);[预测,大摩 Byrd] Blackwell→Rubin→Feynman 成本再降约 75% ⏳
  • 过去两年售价跌得比成本快(单位毛利为负);近半年反转——成本继续降、价格止跌部分小涨;年降价幅度将收窄至 15-25%(大摩 260708)
  • 意义:云厂商 opCF 85%+ 投 capex,token 盈利修复 → capex 空间比市场预判更大
  • 低时延推理的成本核心之一是数据搬运：Jeff Dean 在访谈中确认，从 HBM 向计算单元搬运数据的能耗可达单次乘法运算的约千倍量级；batching 能摊薄搬运成本，却会牺牲交互延迟。因此每 token 成本不只由制程和 FLOPs 决定，还取决于精度、片上存储、内存带宽、batch size 与推理硬件专用化程度。该数量级依赖具体硬件，不能视作跨平台恒定值（来源：Jeff Dean以1%规则解释AI创业机会、推理硬件与Agent系统护城河_Y Combinator_260731）。

杰文斯悖论 vs 支出优化(当前最大多空辩论)

  • 机器请求通胀不等于收入/利润通胀：Cloudflare 披露 2026Q2 非人类流量已超过 50%，管理层并给出五年后最高 1,000 倍于人类流量的高不确定性情景；这支持 Agent 扩大总请求量的杰文斯逻辑。但对网络平台估值，必须继续穿透缓存命中、免费层、合同定价、动态长尾请求成本，以及 Bot Management、Workers/Agent、授权和支付的计费转化，不能把 request growth 直接资本化（来源：AI让人类点击通缩但机器请求通胀，Cloudflare转向Agentic Internet控制平面_Cloudflare_260806）→ 企业AI落地与Agent、云厂商。
  • [多,大摩 Byrd 260630, A-]:6000 行代码仅花 $58(人工需数千美元);企业单次 AI 使用创造约 $55 收益 vs token 成本 $2-3;Ramp 数据显示企业 AI 渗透率不足 1%、单家 token 支出 5 个月 15 倍——支出回撤只来自最早采用的财富 20 强
  • [空,同一人指出]:真正风险是编排层用 2-4 个低成本模型拼出前沿效果(OpenRouter Fusion 已现迹象)→ 前沿模型商品化则价值转移给云厂商
  • [判断,UBS] 企业支出优化是"减速带"非需求反转;模型层受压最大,云与 GPU 硬件层抗压强(260626)
  • Token 增长不等于模型收入质量改善：Chamath Palihapitiya 把 `tokenmaxxing` 定义为模型层的核心经济疑问：若当前收入很大程度来自低效或不良模型行为推高 Token 消耗，缓存、路由、小模型替代和推理优化可能在 Token 总量继续上升时压低年化收入。模型公司应同时披露单位任务 Token、净收入留存、推理毛利和客户 ROI，而非只展示 Token 用量（来源：AI价值捕获短期在电力芯片，长期或迁向Harness与应用层_Chamath Palihapitiya_260801）。
  • OpenRouter 再次验证“用量份额≠支出份额”：高盛称中国模型凭价格优势已占据多数 token 使用量，但支出份额仍明显偏低，低端 Agent/API 价格约 US$0.1-0.2/百万 token。估值应优先跟踪高价值编程/Agent 任务占比、净收入、毛利和实际 ARR，而不是把 token 榜单直接资本化（来源：中国AI模型ARR上调至130亿美元，MiniMax H3与Agent竞争加速_Goldman Sachs Global Investment Research_260804）→ 中国AI投资主线。
  • 需求侧爆点:Agent 单任务交互超 20 次;MiniMax M2 token 2 个月增 6 倍、coding 增 10 倍
  • K3 任务成本案例：Jefferies 人工测评显示，K3 输出价仅为 OpenAI Sol 满配档的一半（15 vs 30 美元/百万 token），但同任务输出 token 为 1.3 亿 vs 7000 万，整套成本 2710 vs 2824 美元。180K 进一步用 Artificial Analysis 的 Cost per Intelligence 图强调，真正应比较“完成单位任务的价格”；其配图转述 Gavin Baker 称 K3 单任务运行成本仍比 GPT-5.6 高 50%-70%。两组口径共同说明单位 token 价不等于单位有效任务成本，但榜单时点、任务集、延迟与重试口径均待核验（来源：K3低价被Token消耗抵消，开源推理同样昂贵_2030FY_260719；K3后六条AI叙事：每智能成本、模型出口、价值迁移、Capex与存储回购_180K_260721）→ Kimi
  • 野村的同日任务口径补强 verbosity 证据：其 2026-07-20 快照给出 K3 约 0.94 美元/AA task、约 62 tok/s，同时生成 Token 约为中位数的 2 倍；这与上述人工测评方向一致，说明低牌价可能被更长输出部分抵消。该数字只代表特定 benchmark/harness，不能替代真实会话的完成率、重试、人审与全链路成本（来源：Kimi K3强化训练推理与AI基础设施需求逻辑_野村_260720）→ Kimi。
  • GLM-5.2 效率案例：智谱口径称 GLM-5.2 平均 60 TPS、高速版约 450 TPS、最新优化可达五六千 TPS,价格约为 Kimi K3 的 1/3。若该口径可复现,说明"小激活参数 + 推理引擎 + KV cache/网络优化"可能比单纯低 API 标价更重要（来源：智谱20260719投资者交流：GLM5.2、Agent RL与Kimi K3对比_智谱_260719，2026-07-19）→ 智谱
  • Cache hit economics：K3/Mooncake 案例说明 cache 命中率和 prefix retention 也是 token 经济性的隐性变量。KV offloading 只有在搬运 KV 的时间低于重新 prefill 时才划算；Mooncake 的 Llama 3 70B 示例显示 8K prefix 在 A800 上至少需要约 6GB/s effective load bandwidth、H800 上约 19GB/s，实际部署还要更高，因为传输无法完全与计算重叠（来源：Kimi K3 KV Cache压缩与DRAM NAND反直觉利好_FUNDA_260722，2026-07-22）→ Kimi、DRAM与HBM供需。
  • 真实 Agent 负载重新定义成本分母：InferenceX 的 K3 代码 Agent 轨迹中，98,827 个 turn 的输入 token p50 为 142k、输出 p50 仅 444、未缓存输入 p50 为 1.7k；393 个会话的 turn 数 p50 为 65。高输入/短输出/高前缀复用意味着应以完整会话的 TTFT、cache hit、单位任务成本和稳定性评估经济性，而非只看输出 TPS 或每百万 token 牌价。OpenRouter 样本中多数路径报价同为 US$3/15，但延迟、吞吐和 uptime 差异明显（来源：Kimi K3架构拆解，KDA、注意力残差、LatentMoE与推理性能_SemiAnalysis_260804）→ Kimi。
  • K3 配额与峰值样本：单一来源纪要称 199 元订阅套餐运行 K3 约 10-12 小时即可耗尽额度，周末高峰出现不可用；随着模型参数增大，推理算力需求可能升至当前 3-4 倍。若属实，这比 API 标价更直接地体现 token/任务需求对供给的吞噬，但套餐限流策略与实际 GPU 消耗尚未拆分（来源：Kimi K3或推动训练推理算力需求成倍增长_来源未知_260721，2026-07-21）→ Kimi、AI资本开支与算力缺口。
  • 开放权重不等于免费：ZeroHedge/Deutsche Bank 把模型分成专有、开放权重与真正开源三类。开放权重可减少 API 付费并支持定制/本地部署，但自托管仍要承担 GPU、电力、利用率、工程维护和安全成本；长期更可能是少数尖端闭源模型与大量开放模型共存，效率下降通过调用量和应用范围扩张触发杰文斯效应，竞争壁垒则从原始权重迁移到专有数据、产品、记忆、安全与推理效率（来源：开放权重模型追赶闭源，AI价值向数据产品与效率迁移_ZeroHedge_260721，2026-07-21）→ 云厂商、AI资本开支与算力缺口。
  • 模型商品化压力与算力飞轮可以同时成立：SemiAnalysis 的三时代样本显示，开放权重追赶窗口由 19.7 个月压缩至 8.5/4.8 个月，缩短闭源 Lab 单代能力溢价的回收期；但其 Tokenomics Model 同时估计前沿 API token 的增量算力收益可达每年每 MW 1 亿美元，而开放 TaaS、企业托管、推荐系统和传统云低于 3000 万美元。若实现收益差持续，头部 Lab 仍可用更高算力报价反哺下一代训练；该组每 MW 数字没有在本文披露底稿，只作待核验的经济性框架（来源：开放模型追赶闭源前沿的周期正在减半但产品与算力仍是护城河_SemiAnalysis_260822）→ AI资本开支与算力缺口、Anthropic、OpenAI。
  • 模型降价与上游成本上涨可以同时发生：The Information 匿名信源称 2027 年交付的 NVIDIA GB300/Rubin 系统拟涨价约 17%，且云厂商可能向租赁客户转嫁；若模型 API 仍因竞争而降价，模型层就会同时面对收入单价下行与推理 COGS 上行。这个价差可解释模型公司盈利承压、GPU/CSP 稀缺租阶段性上升，也说明硬件涨价不是终端需求健康的充分证据（来源：英伟达AI芯片系统拟涨价17%，下一代机柜成本上移_The Information_260822，质量 B）→ 英伟达、云厂商。
  • GPU 租金也必须做质量调整（Barry 8 月 27 日判断）：Rubin 上量后，Blackwell 的名义租金下降可能来自代际迁移和单位算力效率提升，不能单独外推为需求转弱。应把同一 SKU/合约口径租金、每百万有效 Token 的全栈成本、利用率、缓存命中、长约和总 Token 量联合观察；只有全代际量价与订单融资同时走弱，才更接近需求破坏（来源：GPU租金需按单位Token与代际迁移解读，9月反弹宜逢高提款_蔡神与Barry_260827）→ 桨桨观点、英伟达、云厂商。
  • Barry 的“双层垄断租→价格战”框架（8 月 25 日路演判断，待核验）：最前沿能力层仍可能保留高价值租金，成熟高端层则被后发模型、CSP 路由和 Neocloud 共同切分；同等能力下企业会按任务成本选模，因此单位智能价格、而非单一模型榜单，决定模型厂毛利。路演所称成熟层价格倍数已由约 15-20 倍降至约 10 倍、未来可能低于 5 倍，仅为 Barry 单源口径，不进入基准估值（来源：模型价格战与Agent透支形成短多中空长多窗口_杨浩伟_260825）→ 桨桨观点、云厂商、Anthropic。
  • Agent 导流的增长透支（Barry 判断，待核验）：路演认为 OpenAI、Anthropic 在 7 月集中把 Chat 用户导向 Agent，可能同时拉高用户数、ARPU 与 Token 用量，却把本应渐进发生的渗透压缩进 3Q26。验证时应拆开新增用户、付费升档、单位任务 Token、续费/留存和实际消耗收入；若 4Q 留存与收入斜率未降，则“透支”假设不成立（来源：模型价格战与Agent透支形成短多中空长多窗口_杨浩伟_260825；单源 ASR，质量 A）。
  • Ramp 支出 Mix 验证企业按任务经济性路由：FT 报道称，在 Ramp 的 7 万家公司样本中，最强且最贵的 Fable 5 发布两个多月后只占 Anthropic 工具支出的约 11%并已趋平；旧模型能处理多数任务，更便宜的 Opus 5 上线后支出已超过 Fable，GPT 5.6 与开放权重模型也提供低价替代。它验证的是“足够好”模型压缩前沿溢价，而不是 AI 总需求见顶；650 亿美元年化收入与旗舰 Mix 下沉可同时发生。CSP/Neocloud 的利润迁移仍需托管/路由收入、利用率和单位毛利验证（来源：Fable 5支出份额仅11%，企业按任务经济性选模_Financial Times_260823）→ Anthropic、OpenAI、桨桨观点。
  • Firm study 把成本从每次推理前置到可摊销训练：Engram 的 27B 法律 Agent 先学习固定律所工作区，再以参数记忆、1M-token 笔记和选择性搜索回答问题；公开结果为 US$0.13/次、30% all-pass，对比 Opus 4.8 的 US$1.32/次、25% all-pass，完成轨迹 token 降低 58%。这压缩的是单位任务的重复上下文成本，并可能削弱成熟高端 API 的 token 租金；总算力是否下降仍取决于 study 频率、查询量、并发、私有化部署和训练摊销（来源：Harvey以开放模型分层架构实现法律知识持续学习_天风海外_260825）→ 企业AI落地与Agent、AI资本开支与算力缺口。
  • DeepSeek 的单位经济性从二手测算推进到经营信号：The Information 匿名信源称其前七个月 API 毛利率 82.9%、公司整体毛利率 44.6%，支持“官方部署效率可以在低价下保留高毛利”；DeepSeek 官方已把 V4-Pro 输出价调整为高峰/非高峰 US$3.96/1.98 每百万 token，相对报道中的此前 US$0.87 约为 4.55/2.28 倍。若调用量不明显流失，涨价会成为收入与毛利双杠杆；但财务数据未经公司确认，API 毛利也不能外推为公司整体盈利（来源：DeepSeek前7月营收4.75亿元、API毛利率82.9%，第二轮拟融资500亿元_The Information_260825，质量 B）→ DeepSeek。
  • 十个月回本仍是解释框架，不是审计口径：梁文锋此前称 API 按买设备后约十个月回本，2030FY 的二手测算又把高毛利归因于高 cache hit、吞吐与官方部署优化。最新 82.9% API 毛利率与方向一致，但前七个月净亏 7.15 亿元、基础设施投入约 110 亿元说明“单次推理高毛利”与“公司自由现金流为正”不是一回事（来源：梁文锋投资者交流会DeepSeek开源AGI算力商业化_录音文字稿_260716；DeepSeek V4 API 十个月回本与极高毛利率测算_2030FY_260723；DeepSeek前7月营收4.75亿元、API毛利率82.9%，第二轮拟融资500亿元_The Information_260825）→ AI资本开支与算力缺口。
  • GLM-5.2/B300 收入容量测算：单一产业专家称未优化裸机在真实 Agentic 场景可达 31.2 万 tok/s、95% cache hit，满载月收入 192 万元；按 45% 利用率为 86.4 万元，1400 万元现货价对应约 16.2 个月回本。128 台以上集群若靠 PD 分离、大 EP 和跨机 KV 调度把单台月收入抬至 180-260 万元，则回本约 5.4-7.8 个月。算术自洽，但这是收入容量而非已实现收入，仍缺输入/输出占比、缓存折扣、持续吞吐、SLA、电力网络成本和付费售罄率（来源：GLM-5.2在B300上的推理收入容量与集群回本测算_产业专家交流_260726，质量 B）→ 智谱、英伟达。
  • Token 分成把利用率风险转给双方：同一材料称在谈两类模式：租金覆盖运营/财务/折旧后，模型厂与服务器方 5/5 分；或合作方承担全部服务器成本，模型厂/服务器方按 3/7 分。固定租金因此可能转成“成本保底 + 收入分成”，算力方获得上行弹性，但也承担模型降价、流量波动、回款和客户集中风险（同上来源）→ 云厂商。
  • 宏景科技侧验证：分成仍处试运行而非成熟合同：260724 交流称 Token 工厂需要同时完成模型部署、并行/显存优化、PD 分离、GPU 利用率、服务稳定性和收入计量；当前仅有数百台级试运行，先把吞吐或利用率优化到约 60%-70%，但该指标究竟是 MFU、GPU 利用率还是业务达成率仍不清楚。分成可按订阅、API/Token 或“固定订阅+月度浮动”计算，设备出资、电费、包销、空闲转租和收入核验均未定，说明上一份材料的 5/5、3/7 更像谈判方案，不是已跑通的标准合同（来源：宏景科技从算力租赁向Token工厂与泰国IDC升级_宏景科技交流纪要_260724，质量 B）→ 云厂商。
  • MiniMax 训推一体化案例：公司交流称自营推理成本仅为外部头部推理厂商的 1/2-1/3；M3 五折后毛利率约 40-50%、稳态可达 60%，M3 Pro 目标毛利率 50-70%。其解释是 MSA 将 KV cache 压至 M3 的约 1/3，并把模型架构、推理软件、训推混合调度和自建硬件共同优化。若后续财务与实测验证，这说明 token 毛利的核心变量不是单卡采购价，而是全栈利用率和单位有效任务吞吐；当前均为单一公司交流口径（来源：M3 Pro架构、算力自建与Hailuo 3商业化_MiniMax交流纪要_260723，质量 B）→ MiniMax、AI资本开支与算力缺口。
  • Nebius Token Factory 的容量与兑现差：专家纪要给出 B200 按需约 7.85 美元/GPU/小时、Token Factory 约 20-80 美元/GPU/小时、运营及资本成本约 1-2 美元/GPU/小时；高收入端要求客户包销整租并接近 100% 利用率。与此同时，2026 年底 3 亿美元 ARR 目标面临企业实际消耗低于预期和 Token 价格下行，因此这组数字应拆成“技术/商业容量、合同额、实际消耗收入、毛利”四层，而非直接用容量推利润（来源：GPU提价续约支撑短期增长，Token Factory平台化决定中期估值_专家访谈_260812，质量 B）。

  • 大摩类比:美国模型或同时占价值份额+用量份额(复杂任务耗 token 多),类似 Apple/Android
  • HSBC 上调 2030 GenAI TAM 至 7280 亿美元(+44%);2030 份额 OpenAI 32.3%(降)/Anthropic 18.6%(升最快)/Google 11.5%(260401, 预测 ⏳)
  • Outcome-based pricing 可能是下一形态(天风引 OpenAI 押注)

谁把账算正了

  • 先统一 customer spend、GAAP revenue 与 ARR，再比较模型厂毛利：Barclays 用匿名 Lab A/B 情景说明，同样 100 美元 indirect API 客户支出，AI Lab 可因 gross/net 确认与战略云托管分别确认 100、80 甚至 0 美元收入；其 2026 年 paid inference margin 估计为 65%/48%，但推理成本排除免费用户，所谓“训练后毛利”又仅扣最终生产训练 run，未扣主要列入 R&D 的训练成本。跨 Lab 估值应还原终端支出、分产品收入、伙伴分成、production/R&D training 与全成本经营利润；报告的 Lab B 付款和云收入还存在 11 美元不闭环，核心数字均为 Barclays estimates（来源：AI Lab单位经济改善但收入确认与云分成扭曲可比性_Barclays_260828）→ 云厂商、AI资本开支与算力缺口。
  • 二手传播会进一步压缩口径边界：2030FY 的中文精选把匿名 Lab A/B 直接写成 Anthropic/OpenAI，并把仅扣 model production training cost 后的 55%/38%概括为“扣除训练成本后利润率”；它可用于观察卖方结论如何进入市场叙事，但不构成独立证据。跨来源比较仍以 Barclays 原报告为准，并单列 R&D training、免费用户推理和公司级费用（来源：二手精选巴克莱AI实验室盈利模型与CSP收入分成_2030FY_260830）。
  • Anthropic:API 毛利 80%+、3Q26 EBIT 约 10 亿(估算)——正毛利样板
  • Anthropic 260610 专家口径称 Fable 5 为 $10/$50 每百万输入/输出 token，公司毛利率 Q1 约 53%、Q2 全球约 70%；改善归因于 Claude Code 应用收入、TPU 与 prompt caching，但 Q2 尚未结束且产品/公司/地区口径混杂。其“开发者 $100/小时 vs 模型 $20/小时、ROI>300%”也未计重试、人工复核和安全审计，说明真正应比较净任务成本而非 API 牌价（来源：Anthropic企业Agent机器Token驱动ARR，但经营数据口径冲突需核验_GH·CM_260610，待核验）
  • OpenAI:毛利率 39%→目标 52%,靠推理优化(compute multipliers)追赶
